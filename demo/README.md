# Code Tailored Demo

这是一个演示四段式推理的Web应用。

## 功能

- 输入编程问题
- 模型生成结构化响应（decomposition, pseudocode, code, reflection）
- 流式输出
- 前端解析并用不同样式展示各部分

## 运行

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 确保模型在端口35000运行。

3. 启动应用：
   ```bash
   python app.py
   ```

4. 打开浏览器访问 http://localhost:5001
